# Glosario

| Término | Significado canónico |
|---|---|
| PMP | Plan de mantenimiento preventivo mensual importado. |
| OT | Orden de trabajo/mantenimiento externa. |
| Plan de trabajo | Actividad estándar asociada a una OT/activo. |
| Activo | Equipo mantenible identificado por código. |
| Técnico | Persona asignable a turnos y especialidades. |
| Especialidad | Disciplina operativa, por ejemplo MEC, ELE, MET, SER. |
| HH | Horas-hombre: `TiempoEjecucion_min / 60 × NumeroPersonas`. |
| Disponibilidad | HH calculadas a partir de turnos, ausencias y fechas. |
| Capacidad | Disponibilidad transformada por la política operativa aprobada. |
| Programación | Decisión semanal de OT/actividades a ejecutar. |
| Backlog | OT no ejecutada que se conserva para un ciclo posterior. |
| Cierre | Reconciliación de la programación contra la exportación externa. |
| Complemento | Dato manual de TEAM FOOD que completa una fuente incompleta. |
| Source data | Datos importados cuyo origen de negocio es el sistema externo. |
| App-owned data | Decisiones, complementos, historial y auditoría de TEAM FOOD. |
| Estado canónico | Estado interno después de normalizar variantes externas. |
| Import batch | Registro auditable de una carga de archivo. |
| V1 / V2 | Arquitectura histórica / arquitectura activa. |
