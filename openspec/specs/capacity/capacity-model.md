# Modelo de capacidad

La capacidad usa técnicos, especialidades, turnos, ausencias y HH de planes. La documentación actual indica HH = minutos de ejecución / 60 × personas, y el código V2 expone disponibilidad, meta y reserva. Existe una política de “doble 80%” en código/UI y un workflow automático, pero no está resuelta como decisión de negocio. No cambiar la fórmula sin ADR y escenarios de aceptación.
